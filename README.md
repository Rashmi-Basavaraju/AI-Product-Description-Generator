## E-Commerce Product Description Generator Using Generative AI

An AI-powered web application that generates high-quality product descriptions for e-commerce platforms. This project helps reduce manual effort and improves content consistency using Generative AI.

## Project Overview

The AI Product Description Generator allows users to:

* Select or input product details
* Generate AI-based descriptions instantly
* Save generated content
* View previously generated products in a dashboard

##  Objectives

* Automate product description creation
* Improve efficiency and consistency
* Provide a user-friendly interface
* Store and manage generated data

##  Tech Stack

## 🔄 System Workflow

1. User logs in
2. Selects a product
3. Frontend sends request to backend
4. Backend calls AI service
5. AI generates description
6. Response displayed on UI
7. Data saved in database

---

## ▶️ How to Run the Project

### 🔹 Backend (Spring Boot)

1. Open project in IDE (Eclipse / IntelliJ)
2. Configure MySQL database in `application.properties`
3. Run the Spring Boot application

### 🔹 Frontend (React)

```bash
cd frontend
npm install
npm run dev
```
